# Iteration: Analytics, Sprint, Final Recommendation

> Module 6 · Evals & Iteration. Read the analytics, run an iteration sprint, present with evidence.

## What the evidence says

_What real usage showed: numbers if your tool has analytics, counted behaviour if it does not. Put the signal that matters on screen._

- **Primary signal:** Expected booking rate has been achieved
- **What moved:** Products are being reviewed and requested.
- **What didn't:** Providers website, navigation breadcrumb, capabilities to "like" products, enhanced interaction with products in main view

_Observed behaviour: reach 3; core action 2; stall point Accessing vendor's website, products cannot be "liked"; explained away _____; own first run Images on main view are not clickable. Product list should remain more prominent.._

## Iteration sprint

| Change | Hypothesis | Result |
|---|---|---|
| A reduction in the median time to first booking and an increase in the booking rate for zero-review providers | Improved product evidence, enhanced options for contacting or interacting with the provider, a trust panel, verification badges plus early social proof, on new-provider profiles will cause more first bookings for zero-review providers for buyers browsing new providers. | Median time to first booking has decresed. Expected booking rate has been achieved |
